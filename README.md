# Restaurant Management Frontend

This is a feature-based React + TypeScript + Tailwind + Vite SPA for a restaurant SaaS platform.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query
- Zustand
- React Hook Form
- Zod
- Recharts
- Lucide React
- Radix UI

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Environment

Copy `.env.example` to `.env` and update values as needed.
